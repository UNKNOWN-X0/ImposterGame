# Playtest guide

Use this sheet to check whether a new or infrequent host can start and finish a
game without coaching. Do not collect player names or add analytics. Ask before
recording a session; notes can use anonymous labels such as `T1` and `T2`.

## Session script

1. Hand the player the home screen and ask them to start a game using the
   simplest setup. Do not explain the two play modes unless they ask.
2. Ask them to add the group, choose a word language, and deal the cards.
3. Ask them to change one option: select a preset, choose a word pack, or open
   the rule customizer and enable a role.
4. Play one full game and ask them to restart or return to the lobby.
5. For room play, have one person host and another join from a phone on the same
   Wi-Fi. Briefly disconnect one phone and check that it recovers or offers a
   clear next step.

Rotate the play modes and languages across sessions. Include at least one
session each in English, German, and Thai, and try both one-phone and room play.

## Session record

Copy this section for each session and fill it in after play:

```text
Session: T__       Date:
Interface language: en / de / th
Mode: one phone / room
Host had played before: yes / no
Completed setup without help: yes / no
Finished a full game: yes / no
Blocking bug: none / describe
Where they hesitated or asked for help:
What they tried to do next:
Player's suggested improvement:
```

## Acceptance and issue review

- Run at least five sessions with new or infrequent hosts.
- The day-90 target is at least four groups completing setup and a full game
  without help or a blocking bug.
- Record each issue with the session label, screen or step, expected result, and
  actual result. Never include a secret word or a player's private role in a
  bug report.
- After each release, review issues by player impact and maintenance cost. Fix
  blocking issues first; use repeated hesitation across sessions to choose the
  next usability improvement.
